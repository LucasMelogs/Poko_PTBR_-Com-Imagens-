# Pokémon Pokopia — PT-BR com imagens

**MOD feito por Lucasmelogs**

Tradução de fã para português do Brasil, destinada ao Pokémon Pokopia **v1.0.4** (update `327680`). Use o idioma **inglês** no jogo.

## Download

[**Baixar o mod PT-BR — textos + imagens + crédito**](https://github.com/LucasMelogs/Poko_PTBR_-Com-Imagens-/releases/download/v1.0.4-ptbr.1/Pokopia-PTBR-v1.0.4-Lucasmelogs.zip)

O arquivo ZIP contém a pasta `PT-BR/romfs` pronta para instalação e um arquivo `LEIA-ME.txt`. O pacote tem aproximadamente **115,8 MB**.

## Conteúdo

- 22.948 textos traduzidos, com as tags de controle preservadas.
- 37 texturas com texto traduzidas, identificadas por OCR e revisão visual: tutoriais, menus, pedidos, carimbos, culinária, lojas, portão e avisos de minigame.
- Tela de título com **PRESSIONE O BOTÃO Ⓐ** e o crédito **MOD feito por Lucasmelogs**.

## Instalação no Eglantine / Eden

1. Feche o jogo e o emulador.
2. Extraia a pasta `PT-BR` do ZIP em:

   ```text
   %APPDATA%\eden\load\0400A3A01EE4C000\
   ```

3. Se já usa o mod, substitua os arquivos da pasta `PT-BR` anterior.
4. Ative o mod **PT-BR** nas propriedades do jogo e selecione **inglês** como idioma.

A estrutura final deve ficar assim:

```text
0400A3A01EE4C000/
└── PT-BR/
    └── romfs/
        ├── LD_C0_R.BIN
        ├── LI_C0_R.IDX
        └── motor_asset_re/
            └── KIDS_PLATFORM_OUNCE/
                ├── root.rdb
                ├── root.rdx
                └── 0x4b13d561.fdata
```

O mod funciona por LayeredFS; os arquivos originais do jogo não precisam ser alterados. Para desativá-lo, desmarque **PT-BR** nas propriedades do jogo.

## Compatibilidade e revisão

- Destinado exclusivamente à **v1.0.4**; não use na v2.0.1.
- Tags dos textos, integridade dos arquivos e os 37 registros de textura foram conferidos.
- A inicialização e o título traduzido foram testados no Eglantine. A revisão de todas as situações durante uma partida ainda está pendente; o crédito foi adicionado ao pacote, mas sua conferência final no jogo ficou pendente.
- As 37 imagens são o lote identificado por OCR e revisão visual; isso não garante que todo texto desenhado existente no jogo esteja coberto.
